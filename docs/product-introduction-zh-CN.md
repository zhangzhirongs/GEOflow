# GEOFlow 产品介绍

## 一句话定位

GEOFlow 是面向企业内容团队的 GEO（生成式引擎优化）内容工程与多平台运营系统。它把知识沉淀、AI 生成、人工审核、站内发布、跨平台分发、账号与登录态管理、效果分析连接为一条可追踪的内容生产链路，帮助团队持续建设更容易被搜索引擎和大语言模型理解、引用与推荐的内容资产。

## 解决的问题

- 内容生产依赖个人经验，知识和素材难以复用。
- AI 生成缺少统一的品牌、事实和 SEO 约束，质量不稳定。
- 网站、内容渠道和社交平台分散运营，重复编辑、重复登录。
- 多平台账号、登录态和发布权限难以集中管理，状态失效后不易发现。
- 发布之后缺少统一的任务记录、失败重试、回执和数据分析。

## 核心能力

### 1. GEO 内容资产中心

以知识库为基础管理企业资料、行业知识、产品信息和规范文档，支持结构化切片、规则切片、向量化和语义检索（RAG）。标题库、关键词库、图片库、作者库、正文提示词和专题提示词统一沉淀，形成可持续复用的内容资产。

### 2. AI 内容生产与任务调度

支持 OpenAI 兼容接口和 Gemini 等模型，按任务选择模型、提示词、知识库和素材。系统支持批量生成、草稿池、定时调度、队列执行、失败重试、调用统计和任务运行记录；团队可以从单篇创作扩展到规模化内容生产。

### 3. 审核、编辑与 SEO 优化

内容在草稿、审核、发布和回收站之间流转。编辑器支持标题、正文、摘要、关键词、封面图、作者、分类、规范化 HTML 和平台适配；同时生成 SEO 元信息、Open Graph、Schema、GFM Markdown、站点地图、`llms.txt` 等 GEO 友好输出。

### 4. 自有站点与主题管理

系统可直接运营企业官网、行业资讯站、专题站或知识型站点。支持站点设置、栏目分类、主题切换、主题包、预览路由、首页模块、文章详情页和线索表单，并可通过多域名、子域名或目录部署多个内容出口。

### 5. 多渠道分发与发布闭环

通过 GEOFlow Agent、WordPress REST、通用 HTTP API 等渠道，将文章发布到远程站点或目标内容包。每个渠道支持密钥管理、连接测试、远程配置同步、静态/伪静态模式、队列、日志、远程编辑与删除；发布任务可选择“本地与渠道同时发布”“仅渠道发布”或“仅本地发布”。

### 6. 平台账号与登录态管理

GEOFlow 内置统一的发布账号中心。团队可以按人员/角色（Persona）维护多个平台账号，记录账号名称、主页地址、平台标识、发布适配器、备注、执行节点和启用状态，并配置自动发布策略。

支持知乎、小红书、微博、微信公众号、抖音、哔哩哔哩、Reddit、X、LinkedIn 及自定义平台等账号类型。系统可保存平台登录标识和登录态信息，并对登录态进行加密存储；可查看登录态缺失、登录中、有效性检查等状态，按平台执行登录或检查任务。小红书支持登录流程及状态轮询，适合需要保持浏览器会话的发布场景。

账号可绑定执行节点或发布接口，发布任务会关联具体账号，记录执行人、尝试次数、远程 ID、远程 URL、发布时间、失败原因和重试状态。这样既能集中管理账号，也能在团队协作和故障排查时保留完整上下文。

### 7. 人工发布工作台

对于需要人工确认或平台暂无稳定接口的渠道，系统提供人工发布工作单。工作单包含平台、账号、内容快照、负责人、计划时间、风险提示、去重提醒、发布回执和 CSV 导出，兼顾合规审阅与执行效率。

### 8. 数据分析与运营监控

数据分析中心集中展示系统总览、内容运营、任务健康度、素材健康度、分发状态、访问日志、热门内容和 AI 爬虫识别趋势。团队可以按站点、渠道、时间和内容维度评估产出、发布成功率、访问表现与 GEO 可见性。

## 标准工作流

1. 建立知识库、标题库、关键词库、图片库和提示词规范。
2. 配置 AI 模型、内容任务、审核规则和发布范围。
3. AI 生成文章并进入草稿池，编辑人员完成事实、品牌和 SEO 检查。
4. 审核通过后发布到自有站点，并按任务配置分发到目标渠道。
5. 系统按账号、登录态和执行节点执行发布，记录回执并对失败任务重试。
6. 在分析中心查看内容、渠道、访问和 AI 抓取表现，持续优化知识库与提示词。

## 典型使用场景

- 企业官网与品牌内容中心的持续运营。
- 行业媒体、专题站和 SEO/GEO 内容矩阵建设。
- 多品牌、多站点、多语言内容团队的统一管理。
- 需要同时维护自有站点、社交平台和人工发布渠道的团队。
- 需要把账号权限、登录态、发布节点和操作记录集中纳管的机构。

## 产品价值

- **资产化**：把知识、素材、提示词和文章沉淀为可复用资产。
- **标准化**：用模型、规则、审核和模板统一内容质量。
- **规模化**：通过任务、队列和多渠道分发提高产能。
- **可控化**：账号、登录态、权限、发布范围和执行节点集中管理。
- **可追踪**：从生成到远程发布保留任务、回执、错误和审计记录。
- **可优化**：用数据分析反馈内容策略、渠道策略和模型配置。

## 安全与治理

GEOFlow 对管理后台、API 和发布流程进行权限控制，支持 API Token 权限范围、管理员会话保护、操作日志、幂等控制、密钥脱敏和安全审计。平台登录态、发布密钥等敏感信息以加密形式保存，前台和日志不展示原始凭据；生产部署可使用 Docker、PostgreSQL（含向量能力）、Redis、队列、调度器、Reverb 与 Nginx/PHP-FPM。

## 适合的团队

GEOFlow 适合品牌市场团队、内容运营团队、SEO/GEO 服务商、企业知识管理团队，以及需要经营多站点、多平台内容资产的组织。它既可以作为一个内容站点的运营后台，也可以作为企业级 GEO 内容中台和多渠道发布控制台。
